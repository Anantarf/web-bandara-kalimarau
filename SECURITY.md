## Melaporkan Celah Keamanan (Vulnerability Reporting)

Keamanan aplikasi dan data publik **Bandara Kalimarau** adalah prioritas utama. Jika Anda menemukan celah keamanan (*vulnerability*), mohon untuk **tidak** membukanya secara publik melalui GitHub Issues.

### Cara Melaporkan:
- Kirimkan email laporan ke pengelola teknis IT / Administrator Bandara Kalimarau.
- Cantumkan detail langkah-langkah untuk mereproduksi celah (*replication steps*), potensi dampak, dan bukti konsep (*proof of concept*) jika ada.

### Komitmen Respon:
- Tim teknis akan memverifikasi laporan dalam kurun waktu **24–48 jam**.
- Pembaruan keamanan (*patch*) akan disiapkan dan disebar melalui CI/CD sesegera mungkin setelah perbaikan terverifikasi.
